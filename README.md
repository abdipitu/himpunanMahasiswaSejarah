# himpunanMahasiswaSejarah
Website ini dibuat untuk menunjang kegiatan Himpunan Mahasiswa Sejarah Universitas Negeri Semarang.

Terdapat beberapa fitur yang dapat diakses baik mahasiswa umum maupun fungsionaris himpunan.

Akan selalu ada pengembangan dalam setiap waktu dan feedbackmu menjadi berharga bagi keberlangsungan himpunan ini.

- Departemen Publikasi, Sosial dan Budaya
